# 智能购物意见助手 🛒
> 一个免费、中立、轻量化的购物决策辅助网页项目，提供购物咨询、商品对比、场景推荐、购物避坑等功能。

## ✨ 项目亮点
- 🛍️ 快速购物咨询：输入商品、预算和需求，一键获取中立专业的选购建议
- 📊 商品对比工具：快速对比两款商品的优缺点，帮你做出理性选择
- 🎯 场景化推荐：开学/租房/送礼/健身/办公场景，一键查看好物清单
- ⚠️ 购物避坑指南：防刷单、防套路、防诈骗的实用提醒
- 📱 响应式设计：手机、电脑、平板均可流畅访问
- 🎨 现代化UI：卡片悬浮动效、渐变配色、简洁易用的交互界面

## 🛠️ 技术栈
- HTML5
- CSS3 (Tailwind CSS)
- JavaScript
- Font Awesome 图标库
