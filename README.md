# 智能购物意见助手
一个免费、中立、轻量化的购物决策辅助网页项目，提供购物咨询、商品对比、场景推荐、购物避坑等功能。

## 项目介绍
随着电商平台商品种类增多，用户在选购时容易出现选品困难、比价麻烦、怕踩坑等问题。
本项目通过简单易用的网页界面，为用户提供快速、实用的购物建议，适合学生、上班族、中老年用户使用。

## 功能亮点
- 🛒 快速购物意见咨询：输入商品+预算+需求，一键获取建议
- 📊 商品对比工具：快速对比两款商品优缺点
- 🎯 场景化推荐：开学/租房/送礼/健身/办公一键查看清单
- ⚠️ 购物避坑指南：防骗、防套路、防刷单提醒
- 📱 响应式设计：手机、电脑、平板均可正常访问
- ✨ 现代UI界面：卡片布局、渐变风格、悬浮动效

## 技术栈
- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- Font Awesome 图标

## 使用方法
1. 下载或克隆本项目
2. 直接打开 `index.html`
3. 输入需求，即可使用所有功能
